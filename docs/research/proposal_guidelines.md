# Research Project Proposal — Guidelines (source of truth)

## Content (5 sections × 20 marks)

### 1. INTRODUCTION (20 Marks)
- **1.1 Title of the Research** — clear title; main topic/variables; specific; concise
- **1.2 Background of the Study** — research area; current scenario; importance; issues/challenges; need for study
- **1.3 Significance of the Study** — academic value; technical value; practical value; beneficiaries; contribution to knowledge; relevant SDG alignment
- **1.4 Aim, Objectives, Research Questions & Hypothesis** — Aim (overall purpose); Objectives (3–5 measurable points); Questions (based on objectives); Hypothesis

### 2. LITERATURE AND RESEARCH FOUNDATION (20 Marks)
- **2.1 Literature Review** — previous studies; key findings; theories/concepts; variables; methodologies; limitations
- **2.2 Theories, Concepts & Existing Methodologies** — relevant theories; key concepts; variables; existing methods; strengths/limitations
- **2.3 Research Gap** — previous work; missing areas; limitations; unresolved issues; proposed gap solution
- **2.4 Research Framework / Conceptual Framework** — major variables; variable relationships; theoretical basis; framework diagram; explanation

### 3. RESEARCH PROBLEM AND DESIGN (20 Marks)
- **3.1 Research Problem** — clear problem; issue to investigate; key variables; existing deficiency; problem impact
- **3.2 Research Approach** — quantitative/qualitative/mixed; selected approach; justification
- **3.3 Research Design** — experimental/survey/simulation/analytical/case study/development; selected design; justification
- **3.4 Scope of the Research** — research area; population; variables; conditions; applications; exclusions

### 4. RESEARCH IMPLEMENTATION AND EVALUATION (20 Marks)
- **4.1 Data Collection** — data source; primary/secondary data; collection method; sample/data size
- **4.2 Tools and Techniques** — software; hardware; instruments; algorithms; methods; techniques
- **4.3 Data Analysis and Performance Measures** — analysis methods; parameters; statistical/mathematical techniques; performance metrics; comparisons
- **4.4 Expected Outcomes** — expected findings; improvement; proposed solution/model; expected performance

### 5. RESEARCH MANAGEMENT AND OUTPUT (20 Marks)
- **5.1 Limitations** — technical; data; resource; time; financial; methodological
- **5.2 Research Work Plan & Gantt Chart** — activities; timeline; milestones; deliverables; Gantt chart
- **5.3 Cost Estimation / Budget (tabular)** — equipment; software; data collection; materials; travel; testing; publication; miscellaneous; total
- **5.4 Expected Contribution, Ethical Considerations & References** — contribution (knowledge; technical; practical; methodological); ethics (approval; consent; privacy; data security; plagiarism); references (papers; books; conferences; reports; consistent style e.g. IEEE; every cited source in the reference list)

## Formatting

| Element | Format |
|---|---|
| Font | Times New Roman |
| Main title | 16–18 pt, bold, UPPERCASE or Title Case, centred; 0 pt before, 12–18 pt after |
| Chapter/section title | 14–16 pt, bold |
| Major heading | 14 pt, bold |
| Sub-heading | 12 pt, bold |
| Sub-sub-heading | 12 pt, bold/italic |
| Body text | 12 pt regular, justified, 1.5 spacing, 0 pt before / 6 pt after |
| Headings | left aligned, 12 pt before / 6 pt after |
| Abstract | 1.5 spacing, 150–300 words |
| Keywords | 12 pt |
| Table text | 10–11 pt; caption 10–12 pt **above** table |
| Figure/chart text | 10–11 pt; caption 10–12 pt **below** figure |
| Footnotes | 10 pt |
| References | 12 pt, 1.0 or 1.15 spacing, 6 pt after each |
| Long quotation | 12 pt, indented, single-spaced |
| First-line indent | 0.5 in / 1.27 cm, if required |
| Margins | 1 in / 2.54 cm all sides |
| Paper | A4, portrait |
| Page numbers | bottom-right or bottom-centre, 10–12 pt |
